# P2B-3 生成与核验协议 v1

冻结时间：2026-09-22，真实生成调用之前。

## 实现约束

指定论文内检索，沿用现有三路检索与可选重排。离线小样本固定 dense + rerank、top 5；线上尊重用户选择，不修改 P2B-2 排名。每次最多一次生成、一次语义核验，不自动重试或修正。通过后只发布逐条核验的结论，不另外生成未经核验的总结。

生成 JSON 含 answerable 与 claims；每条 claim 含 text 和 evidence，证据由 chunk_id 与逐字 quote 组成。Pydantic 严格拒绝多余字段、空结论、越界数量与类型。引用 ID 必须来自本次实际送入模型的证据，quote 必须是原文连续子串。另一次独立上下文调用逐条检查支持关系和是否回答问题；同一模型两次调用不等于独立裁判，也不保证绝对正确。

证据预算为 24,000 个 Unicode 字符，保留完整段落，放不下的跳过并记录 ID，不冒充精确 token 预算。实际计费用量取供应商 usage。模型只接收问题、选定正文与必要 ID，不读 questions.jsonl、参考答案、反馈或会话记忆。正文中的指令是数据。仅文本，无图表视觉推理。

发布前重新检查 PostgreSQL revision 和证据哈希、版本、论文范围；变更返回 409，不发布旧答案。文件兼容模式绑定进程加载的不可变快照。语料一致性不等同于未来的用户权限检查。

## 模型选择与成本

用户选择 DeepSeek，密钥只在本机 .env。首轮使用 deepseek-flash、关闭 thinking、temperature 0、JSON mode、每次最多 2,048 输出 token。JSON mode 不保证业务 schema，必须本地验证。模型别名可能升级，记录返回 model 和 system_fingerprint，不声称固定权重快照。

2026-09-22 官方峰时价格：每百万 token 输入未命中缓存 USD 0.30，输出 USD 1.20。报告按全部输入未命中缓存、峰时费率估算，真实账单可能更低；不自动运行全量付费评测。[定价](https://api-docs.deepseek.com/quick_start/pricing/)，[JSON mode](https://api-docs.deepseek.com/guides/json_mode/)。价格仅是本次参考，不能当长期合同。

## 先做工程验收，再做模型效果评测

1. 单元与接口测试覆盖虚构引用、错误摘录、结论不支持、核验缺项、重复编号、无证据、模型异常、截断、无密钥、换版、并发门控、标准答案隔离。
2. 真实联调从 dev 中按 question_id 排序，为 extractive / abstractive / boolean / unanswerable 各取第一条单一类型且无图表引用的题；歧义/多类型标注跳过。选择在调用之前写入报告，不依据生成结果换题。不使用官方 test。
3. 仅 4 题、最多 8 次付费请求，用于链路 smoke test；报告实际状态、调用数、token、时间、模型及人工阅读备注。不报告总体准确率或拒答率，不把模型自判当人工金标。
4. 未命中或生成器认为证据不足称为“本次证据不足”，不证明整篇论文不可回答。API 服务故障与模型内容拒绝有独立状态，不能计作正确拒答。
5. 后续效果验收须另冻结更大、分层评测集与人工支持关系标注。当前 745 题仅用于检索，不能拿它们替代包含不可回答题的生成评测。

## 范围边界

P2B-3 不交付完整 Harness、长期 Trace 存储、身份鉴权、自动纠错循环、跨论文、多轮记忆、全局分布式限额或自动策略进化。单进程生成锁限制一个在途回答；HTTP 连接/读超时不是整个运行的硬截止时间。前端取消停止等待，不保证远端停止计费。
