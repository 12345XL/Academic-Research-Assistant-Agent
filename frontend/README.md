# 论文检索工作台前端

React + TypeScript + Vite。当前阶段直接展示 BM25 检索得到的原文，不生成回答；所有论文、段落、存储状态和任务记录均来自后端 API。

## 本地运行

需要 Node.js `^20.19.0` 或 `>=22.12.0`。在当前目录执行：

```sh
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173`。后端必须运行在 `http://127.0.0.1:8011`；Vite 将 `/api` 和 `/health` 转发给后端。前端只使用同源相对 URL，不需要在浏览器配置数据库或对象存储凭据。

```sh
npm run build
npm test
```

构建产物位于 `dist/`。`npm run preview` 可在本机预览构建结果；它与开发服务器使用同一端口，不能同时启动。正式部署仍需配置静态资源服务器与 API 反向代理，此阶段未做公网部署。

## 页面与数据

- 论文工作台：标题搜索、分页、选择论文、查看摘要、打开/下载官方 arXiv PDF、提交指定论文内的检索、调整返回条数；先按聚合研究方向筛选，再按编号、标题、arXiv 首次提交时间或 CCF 发表载体等级排序。
- 原文证据：显示段落、章节和相关性分数；打开相邻段落核对上下文；通过后端下载校验后的结构化 JSON 原文。
- 数据与存储：展示论文/段落/文件对象数量、PostgreSQL 和对象存储状态、最近 20 条导入任务。
- 服务中断时显示真实错误；系统状态与任务列表独立加载，避免任务失败掩盖数据库故障。
- 切换论文会清除旧问题和证据，并取消尚未完成的请求。检索也可以主动取消。

BM25 分数是相关性排序值，不是置信度。当前英文词项检索不支持中文语义匹配。未检索到段落不能推断论文无法回答。

方向来自 arXiv 官方主分类的确定性聚合；交叉分类不会让同一论文重复出现在多个方向。时间标签表示第一版提交 arXiv 的日期，不表示正式出版日期。CCF 标签表示已核实发表载体在官方目录中的级别，不是论文质量分。原论文 PDF 来自外部 arXiv 链接；RAG 结构化正文来自本地对象存储并做 SHA-256 校验，两者在界面中分别标明。

## 代码阅读顺序

1. `src/api.ts`：HTTP 请求、错误传播、分段加载上下文和下载原文。
2. `src/App.tsx`：论文选择、请求生命周期、检索结果和存储状态的页面状态。
3. `src/styles.css`：桌面双栏和手机横向论文列表、对话框、加载与错误布局。
4. `src/api.test.ts`、`src/App.test.tsx`：跨页上下文、取消请求、旧结果隔离、失败重试和部分服务失败等行为测试。

自动化测试使用限定的接口返回值验证状态边界；页面运行时没有 mock 数据或虚构指标。
